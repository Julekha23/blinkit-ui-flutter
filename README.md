# 🛒 Blinkit UI Clone (Flutter)

A Flutter application that recreates the **Blinkit** grocery delivery app UI. This project focuses on building a clean, responsive, and reusable user interface using Flutter and Dart.

## ✨ Features

- Splash Screen
- Login Screen
- Home Screen
- Category Screen
- Product Cards
- Bottom Navigation Bar
- Responsive UI
- Reusable Widgets
- Clean Folder Structure

## 📂 Project Structure

```
lib/

├── Data/

├── domain/

```

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Julekha23/blinkit-ui-flutter.git
```

### Navigate to the project

```bash
cd blinkit-ui-flutter
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```

## 📌 Folder Description

| Folder | Description |
|---------|-------------|
| `Data` | Stores local/static data used in the app. |
| `domain/const` | Application constants such as colors and themes. |
| `domain/repository` | Repository layer for data management. |
| `screens` | Contains all UI screens of the application. |
| `widgets` | Reusable widgets and helper methods. |
